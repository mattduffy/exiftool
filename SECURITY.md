# Security Policy

## Supported Versions

Security updates will be provided back to package version 1.15.0.

| Version | Supported          |
| ------- | ------------------ |
| 1.15.0  | :white_check_mark: |
| < 1.14.1| :x:                |

## Reporting a Vulnerability

If you have found a vulnerability in the code in this npm package, please do not open a public issue, pull request or discussion.

To report a vulnerability, please use the **Report a Vulnerability** form under the **Security and Quality** tab.

You may also report the vulnerability directly to mattduffy@gmail.com.
